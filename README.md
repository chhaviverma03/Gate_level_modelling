# Gate Level Modelling

This repository contains digital logic circuits implemented using **Gate-Level Modelling in Verilog HDL**.

The designs are built using Verilog's built-in **gate primitives** such as `and`, `or`, `not`, `nand`, `nor`, `xor`, and `xnor`.
